Upstream Tcl/Tk license notices preserved verbatim for redistributions.
Both the Tcl/Tk 8.6 and 9.0 notices are included because supported native
Python distributions can carry either major line. Build scripts also retain
any license notices present in the actual Tcl/Tk installation.

Sources (official upstream, retrieved 2026-10-09):

https://github.com/tcltk/tk/blob/core-8-6-14/license.terms
https://github.com/tcltk/tcl/blob/core-9-0-4/license.terms
https://github.com/tcltk/tk/blob/core-9-0-4/license.terms
