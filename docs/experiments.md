# 三组教学实验

**全部曲线和导出文件均为合成仿真数据，没有硬件连接。** 本实验台用于理解信号处理，不代表任何真实仪器的性能、标定或认证。

第一次使用可先读 [15 分钟上手指南](tutorial.md)，其中附有固定 seed 的图、完整设置和可验证答案。本页提供进一步练习与数学参考。

界面预设名称使用英文。载入预设后运行仿真；每次实验只改变一个参数，并保存一份 JSON 设置和 PNG。幅值单位为 V，频率为 Hz，时间为 s，相位为度。

| 预设 | 主信号峰值 / 相位 | 噪声标准差 | 干扰峰值 / 频率 | 时长 / 锁相截止频率 |
| --- | --- | --- | --- | --- |
| Clean reference | 1 V / 30° | 0 V | 0 V / 120 Hz | 4 s / 2 Hz |
| Buried in noise | 0.2 V / −45° | 2 V | 0.6 V / 120 Hz | 6 s / 1 Hz |
| Nearby interference | 1 V / 60° | 0.1 V | 0.8 V / 53 Hz | 8 s / 1 Hz |

三组均使用 2000 Hz 采样率、50 Hz 主信号与参考、80 Hz 输入低通和 seed 42。零幅值干扰仍保留一个有效频率参数。

## 1. Clean reference · 核对增益与相位

这个预设使用 1 V 峰值、50 Hz、30° 的主信号，关闭噪声和干扰，参考频率与主信号匹配。

1. 运行预设，观察 X/Y 从零状态开始的启动瞬态。保守稳定标记之后，估计应接近 `R = 1 V`、`φ = 30°`；有限记录与残余纹波使它们不必逐位等于设定值。
2. 由 `X ≈ A cos φ`、`Y ≈ A sin φ` 推算 `X ≈ 0.866 V`、`Y ≈ 0.500 V`。这里负号位于 Y 混频器中，因此输入正相位会得到正 Y。
3. 把主信号相位改成 −60°，预测 X/Y 的符号后再运行。把幅值改成 0.5 V，检查估计是否大致减半。
4. 比较输入频谱与单级低通后的频谱。输入滤波器会衰减 50 Hz，锁相仍从原始输入混频，因此输入低通截止频率不会直接改变锁相路径。
5. 把主信号、噪声、干扰和直流偏置全部设为 0。幅值应为 0，相位应为未定义，不能读成确定的 0°。

记录：设定的 A/φ、稳定区间、估计的 X/Y/R/φ、输入滤波前后的 50 Hz 谱线幅值。不要把 1 V 峰值写成 1 V RMS；纯正弦 RMS 为 `A/√2`，峰峰值为 `2A`。

## 2. Buried in noise · 可复现噪声与带宽

这个预设把 0.2 V 峰值主信号放在标准差为 2 V 的高斯噪声中，并加入 120 Hz 干扰。高斯噪声参数是总体标准差，不保证有限样本记录的 RMS 恰好为 2 V。

1. 连续运行同一份设置两次，比较曲线或导出的 CSV。相同 seed、参数与软件环境会得到相同的随机样本，便于复现实验。
2. 仅改变 seed，再次运行。噪声轨迹与误差会变化，不能用一次随机实现证明检测准确度。
3. 降低锁相低通截止频率，比较 X/Y 稳态波动；较窄带宽通常减少远离参考频率的噪声，也延长启动时间。
4. 若出现未充分稳定提示，延长记录时长。只有在保守启动时间后至少保留三个参考周期，结果才标为稳定。短记录中的估计仍可显示，但仅供观察，不能当成已稳定结果。
5. 比较原始时域曲线、50 Hz 附近频谱与锁相曲线。锁相不是消除所有噪声；靠近参考频率的噪声仍会通过有限带宽。

记录：seed、锁相截止频率、时长、稳定状态、估计值。可用多个 seed 重复实验，再比较误差分布；不要只挑选最接近设定值的一次。

## 3. Nearby interference · 邻频干扰与失配

这个预设使用 50 Hz 主信号和 53 Hz 干扰。两者仅相差 3 Hz，适合观察有限选择性与拍频。

1. 保持参考为 50 Hz，观察混频后的 X/Y。53 Hz 干扰会在低频端产生 3 Hz 分量；低通对它的抑制程度取决于截止频率。
2. 降低锁相截止频率并延长记录，比较低频波动和稳定时间。较窄带宽不会瞬间收敛，也不代表可无限缩短实验。
3. 把参考频率改成 49 Hz，保留主信号频率 50 Hz。主信号相对参考以 1 Hz 转动，X/Y 不再收敛到固定相位；界面会提示参考频率失配。
4. 比较 `mean(hypot(X,Y))` 与界面估计 `hypot(mean(X),mean(Y))` 的含义。界面使用后者，即对复数矢量求平均；失配时旋转矢量会相消，即使逐时刻幅值并不小，平均幅值也可能下降。
5. 恢复 50 Hz 参考，改变记录时长，观察 FFT 频率分辨率 `Δf = fs/N = 1/T`。非整周期信号会产生矩形窗泄漏；邻近谱线不能总靠一个频点读数可靠分开。

记录：主信号/干扰/参考频率、锁相截止频率、记录时长、频率分辨率、警告信息，以及改变参数后对拍频的解释。

## 数值约定与可解释范围

### 信号与采样

```text
clean(t) = A cos(2π f t + φ) + DC
input(t) = clean(t) + noise(seed, σ) + B cos(2π f_interference t + ψ)
N = round(fs × T)
t[n] = n/fs, n = 0, …, N−1
```

`fs × T` 必须在数值容差内为整数。记录包含 N 个样本，最后一个样本在 `T − 1/fs`；不重复 `T` 端点。噪声使用确定的 seed 生成独立高斯样本。seed 有助于复现，但不构成统计质量或实际仪器噪声模型的保证。

### 因果低通

单级低通采用离散 RC 递推，初始输出为 0：

```text
r = exp(−2π fc/fs)
y[n] = (1 − r) x[n] + r y[n−1], y[−1] = 0
H(eʲω) = (1 − r) / (1 − r e⁻ʲω)
```

输入滤波使用一级；锁相 X/Y 各使用两级串联。滤波由过去和当前样本决定，没有前后向零相位处理，也不裁掉瞬态。`fc` 是用于系数计算的连续 RC 参数；接近 Nyquist 时，不能假定离散系统在该频率恰好是 −3 dB，应使用上面的离散传递函数检查实际增益与相位。

### 双相锁相与结果区间

```text
X = LP₂( 2 input(t) cos(2π f_ref t))
Y = LP₂(−2 input(t) sin(2π f_ref t))
X_est = mean(X over estimate interval)
Y_est = mean(Y over estimate interval)
R_est = hypot(X_est, Y_est)
φ_est = atan2(Y_est, X_est)
```

稳态、频率匹配且干扰足够小的情况下，结果接近主信号峰值 A 与相位 φ。图上的逐时刻幅值与相位来自对应样本的 X/Y；结果区使用平均 X/Y 计算，不是先对逐时刻相位做普通算术平均。

混频还会产生二倍参考频率分量。离散采样下该分量可能折叠到低频，因此锁相截止频率应远低于参考频率，并考虑参考与 Nyquist 的距离；参考接近 Nyquist 时，即使其本身未混叠，二倍频项仍可能难以滤除。

保守启动时间为：

```text
t_settle = max(7/(2π fc_input), 10/(2π fc_lockin))
```

只有在该时间后至少保留三个参考周期，结果才标为已稳定，并使用标记后的区间取平均。否则使用最后 20% 记录给出临时估计，同时显式提示未充分稳定。启动标记不是准确度保证；频率失配、噪声、残余二倍频与有限记录都可能留下误差。

当幅值 `R ≤ 1e−10 × max(1, max(abs(input)))` 时，相位视为数值上未定义：结果相位为 `None`，逐时刻相位使用 `NaN`。这是防止给零矢量指定角度的数值阈值，不是置信区间，也不是统计显著性判断。

### FFT 单边峰值幅度谱

使用矩形窗，先计算 `abs(rfft(x))/N`，再只对具有负频率对应项的频点乘以 2：

- DC 不加倍。
- N 为偶数时，最后一个频点为 Nyquist，不加倍。
- N 为奇数时，最后一个频点小于 Nyquist，需要加倍。

整周期纯余弦会在对应频点显示其峰值幅度。非整周期记录会发生泄漏；本项目不自动做窗函数或幅值插值补偿。频谱单位是 V，既不是功率谱，也不是 `V/√Hz` 噪声谱密度。

### 输入范围

| 参数 | 接受范围 |
| --- | --- |
| 采样率 | `1e−6 ≤ fs ≤ 1e9 Hz` |
| 时长 | `0 < T ≤ 1e9 s`；并满足采样数限制 |
| 样本数 | `16 ≤ N ≤ 1,000,000`，`fs × T` 为整数 |
| 主信号、干扰和参考频率 | 严格大于 0，严格小于 `fs/2` |
| 两个低通截止频率 | 严格大于 0，严格小于 `fs/2`；系数不能舍入成 1 |
| 主信号/干扰峰值、噪声标准差 | `0 … 1e6 V` |
| 直流偏置 | `−1e6 … +1e6 V` |
| 主信号/干扰相位 | `−360000 … +360000°` |
| 随机 seed | 整数 `0 … 2³²−1` |

全部浮点参数必须为有限实数。上述范围是保护数值和内存的输入约束，不表示仿真在每个极端组合下都有教学价值，也不代表硬件量程。很长时间或大量周期可能降低浮点相位精度，应优先选择可解释的教学参数。

## 导出与复现

保存 JSON 设置以保留所有输入参数和 seed；CSV 保存时域结果及合成数据说明；PNG 保存可读的曲线图。导出的未定义相位应继续视为缺失/未定义，不能替换为确定的 0°。记录软件提交版本和依赖环境，有助于跨环境比较。导出结果可用于教学报告，但应保留合成仿真标签。

CSV 文件开始处有 `#` 元数据行；读取表格时跳过这些行。未定义的相位导出为空单元格。以下例子只使用 Python 标准库：

```python
import csv

with open("output/simulation.csv", encoding="utf-8", newline="") as stream:
    samples = list(csv.DictReader(line for line in stream if not line.startswith("#")))

first_sample_time = float(samples[0]["time_s"])
first_phase = samples[0]["lockin_phase_deg"]
first_phase = float(first_phase) if first_phase else None
```

运行 `python -m pytest tests -m 'not gui'` 检查数值约定与导出回读。CI 是否通过应查看对应提交的 [Actions](https://github.com/bte808/virtual-instrument-lab/actions) 记录。图形界面检查需要可用桌面；Windows 数值测试通过不等于 Windows GUI 已经人工验证。
